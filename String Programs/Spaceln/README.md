# Space to New Line

A Java program that takes a sentence as input and prints each word on a new line
by replacing every space with a line break.

## Package
`String`

## How It Works
- Reads a full line of input using `Scanner`.
- Iterates character by character through the string.
- If the current character is a space, moves to a new line (`System.out.println()`).
- Otherwise, prints the character as-is on the current line.
