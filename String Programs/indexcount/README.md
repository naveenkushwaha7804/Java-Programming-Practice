# Character at Index

A simple Java program that takes a string input from the user and prints the character present at a specific index (index 3).

## How it works
- Takes a string input from the user via Scanner
- Fetches the character at index 3 using `charAt()`
- Prints that character

## How to run

```bash
javac indexcount.java
java String.indexcount
```
