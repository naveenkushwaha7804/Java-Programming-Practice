# Palindrome Checker

A simple Java program that checks whether a given string is a palindrome or not.

## How it works
- Takes a string input from the user
- Reverses the string character by character
- Compares original string with reversed string
- Prints whether it's a palindrome or not

## How to run

```bash
javac palendrom.java
java String.palendrom
```
