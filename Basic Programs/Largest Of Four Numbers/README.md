# Largest of Four Numbers

## Description

This Java program takes four integer values as input and determines which value is the largest using conditional statements.

## Approach

- Take four integer inputs using `Scanner`.
- Compare the values using `if-else if-else` conditions.
- Display the largest value.

## Concepts Used

- Java
- Scanner
- User Input
- if-else Statements
- Comparison Operators
- Logical AND (`&&`)
