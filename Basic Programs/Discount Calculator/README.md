# Discount Calculator

## Description

This Java program calculates the final price after applying a discount based on the entered amount.

## Discount Rules

| Amount | Discount |
|---|---:|
| Up to ₹200 | 5% |
| ₹201 – ₹400 | 12% |
| ₹401 – ₹800 | 15% |
| ₹801 – ₹1500 | 25% |
| Above ₹1500 | 25% |

## Approach

- Take the amount as input using `Scanner`.
- Determine the applicable discount using `if-else` conditions.
- Calculate the discount amount.
- Subtract the discount from the original amount.
- Display the final price.

## Concepts Used

- Java
- Scanner
- User Input
- if-else Statements
- Arithmetic Operators
- Conditional Logic

## Complexity

- **Time Complexity:** O(1)
- **Space Complexity:** O(1)
