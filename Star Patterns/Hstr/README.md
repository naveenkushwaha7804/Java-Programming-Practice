# Star Pattern - Letter H

Java program jo user se size `n` leta hai aur stars (`*`) ka use karke
letter **"H"** shape print karta hai.

## Pattern Logic
- Left column → hamesha stars (j==0)
- Right column → hamesha stars (j==a-1)
- Middle row → poori row stars (i==a/2-1)
- Baaki sab jagah blank space

## How to Run
\`\`\`bash
javac Hstr.java
java Star.Hstr
\`\`\`

## Sample Input/Output
Input:
\`\`\`
5
\`\`\`

Output:
\`\`\`
*   *
*   *
* * *
*   *
*   *
\`\`\`
